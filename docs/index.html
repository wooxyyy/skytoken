Технические материалы и quick start.

Версия: v1.3 · Последнее обновление: 2 марта 2026 года

Юрисдикция: Limisky token Foundation (Швейцария, некоммерческая организация). Токен: SKY (ERC-20 / Arbitrum).

Легенда проекта: Limisky token — это децентрализованная P2P-сеть для аренды вычислительных мощностей GPU/CPU для AI/ML.

This documentation provides a high-level technical overview and quick start.

1. Quick Start (Поставщики)

  • Требования: Windows/Linux, NVIDIA GPU, 8GB+ RAM, 100GB+ disk.
  • Установка ноды:
docker pull limiskytoken/node:latest

docker run -d \
  --name limiskytoken-node \
  -e SKY_TOKEN=YOUR_API_KEY \
  -p 30303:30303 \
  limiskytoken/node:latest

Привязка кошелька выполняется через CLI-помощник после установки.

2. Quick Start (Потребители)

  • Подключение к ноде через SSH/RDP.
  • Установка CUDA, PyTorch, TensorFlow.
  • Примеры задач: инференс Stable Diffusion, обучение LLaMA.
# пример: запуск контейнера с CUDA
nvidia-smi
python -c "import torch; print(torch.cuda.is_available())"

4. API Reference

  • GET /api/v1/nodes — список активных нод
  • POST /api/v1/orders — создание заказа
  • GET /api/v1/orders/{id} — статус заказа

WebSocket: wss://api.limiskytoken.io/v1/logs

5. FAQ по запуску ноды

  • Проблемы с NAT/Firewall: откройте порты 30303 и 8545.
  • Требования к сети: рекомендуется 100 Mbps+.
  • Стабильность: используйте UPS и мониторинг.

6. Security

Не передавайте приватные ключи третьим лицам. Используйте отдельные адреса для нод. Bug Bounty Program будет объявлена дополнительно.
